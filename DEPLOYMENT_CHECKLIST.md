## Environment Variables Required

### Database & Redis (Auto-configured by Render)
- `DATABASE_URL` - PostgreSQL connection string
- `REDIS_URL` - Redis connection string

### Rails Configuration
- `RAILS_MASTER_KEY` - Rails master key for credentials
- `SECRET_KEY_BASE` - Rails secret key base (auto-generated by Render)
- `RAILS_ENV=production`
- `RAILS_LOG_TO_STDOUT=true`
- `RAILS_SERVE_STATIC_FILES=true`

### Stripe Configuration
- `STRIPE_SECRET_KEY=sk_live_...` (Live mode key)
- `STRIPE_PUBLISHABLE_KEY=pk_live_...` (Live mode key)
- `STRIPE_WEBHOOK_SECRET=whsec_...` (Webhook signing secret)

### Twilio Configuration
- `TWILIO_ACCOUNT_SID=AC...`
- `TWILIO_AUTH_TOKEN=...`
- `TWILIO_PHONE_NUMBER=+1...`
- `TWILIO_WHATSAPP_NUMBER=+1...`

### Email Configuration
- `SENDGRID_API_KEY=SG...`
- `DEFAULT_FROM_EMAIL=noreply@yourdomain.com`

### App Configuration
- `APP_HOST=https://yourapp.onrender.com`

## Deployment Steps

### 1. Create Render Account
1. Go to [render.com](https://render.com)
2. Sign up for an account
3. Connect your GitHub repository

### 2. Deploy Using Blueprint
1. In Render dashboard, click "New +"
2. Select "Blueprint"
3. Connect your GitHub repository
4. Select the `render.yaml` file
5. Click "Apply"

### 3. Set Environment Variables
1. Go to your web service in Render dashboard
2. Navigate to "Environment" tab
3. Add all required environment variables listed above
4. Repeat for the Sidekiq worker service

### 4. Initial Setup
1. Wait for first deployment to complete
2. Run migrations: `bundle exec rake db:migrate` (via Render shell)
3. Create seed data (optional): `bundle exec rake db:seed`

### 5. Configure External Services

#### Stripe Webhooks
1. Go to Stripe Dashboard > Webhooks
2. Add endpoint: `https://yourapp.onrender.com/webhooks/stripe`
3. Select events: `checkout.session.completed`, `payment_intent.succeeded`
4. Copy webhook signing secret to `STRIPE_WEBHOOK_SECRET`

#### Twilio Webhooks
1. Go to Twilio Console > Phone Numbers > Manage > Active Numbers
2. Configure webhook URL: `https://yourapp.onrender.com/webhooks/twilio_status`
3. Set HTTP method to POST

#### SendGrid Configuration
1. Verify your domain in SendGrid
2. Set up SPF, DKIM, and DMARC records
3. Configure sender authentication
